# javascript-calculator-precourse

## 구현목록 (입력한 문자열에서 숫자를 추출하여 더하는 계산기 구현)

### ✅ 기능 구현
- [x] 문자열에서 쉼표(,) 또는 콜론(:) 구분자 존재 여부 확인
    - [x] 구분자가 없는 경우, 그대로 반환
    - [x] 구분자가 있는 경우, 구분자를 기준으로 문자열 분리
- [x] 앞의 기본 구분자 외 커스텀 구분자 존재 확인
    - [x] 커스텀 구분자(//, \n)이 있는 경우, 둘 사이에 위치하는 커스텀 구분자 체크 및 반환
    - [x] 커스텀 구분자(//, \n)이 없는 경우, 위의 기본 문자열 확인 절차로 진행

### ❌ 에러 확인
- [x] 사용자 입력이 숫자를 포함한 문자열이 아닌 경우
    - [x] 텍스트 문자열인 경우
    - [x] 입력 문자열에 음수가 포함된 경우

### ♻️ 리팩토링
- [x] 유저 입력 클래스 생성
    - [x] 유저의 문자열 입력
    - [x] 입력한 문자열의 구분자 확인 후 분리
- [x] 유효성 검사 클래스 생성
    - [x] 문자열 내 숫자가 아닌 문자 존재 여부 확인 메소드
    - [x] 문자열 내 음수 포함 여부 확인 메소드
- [x] 게임 클래스 생성
    - [x] 분리된 숫자들을 더하기
    - [x] 더해진 숫자의 결과 출력
