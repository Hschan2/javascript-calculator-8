# javascript-calculator-precourse

## 구현목록 (입력한 문자열에서 숫자를 추출하여 더하는 계산기 구현)

### ✅ 기능 구현
- [ ] 문자열에서 쉼표(,) 또는 콜론(:) 구분자 존재 여부 확인
    - [ ] 구분자가 없는 경우, 그대로 반환
    - [ ] 구분자가 있는 경우, 구분자를 기준으로 문자열 분리
- [ ] 앞의 기본 구분자 외 커스텀 구분자 존재 확인
    - [ ] 커스텀 구분자(//, \n)이 있는 경우, 둘 사이에 위치하는 커스텀 구분자 체크 및 반환
    - [ ] 커스텀 구분자(//, \n)이 없는 경우, 위의 기본 문자열 확인 절차로 진행

### ❌ 에러 확인
- [ ] 사용자 입력이 숫자를 포함한 문자열이 아닌 경우
    - [ ] 텍스트 문자열인 경우
    - [ ] 입력 문자열에 음수가 포함된 경우
